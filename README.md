# Literary Cats

Meet the cats of literature.

[Explore the archive](https://www.denkibrew.com/literary-cats/)

Literary Cats is a small, growing archive of cats in literature. Each entry introduces a character, its author and original work, and its place in the story, accompanied by book covers, illustrations, and other visual references.

The site has a literary-newspaper-inspired layout. Browse entries by date, or search for a character, work, or author.

## About the content

A scheduled ChatGPT task collects and organizes new entries daily. This repository stores the articles, reference images, and character index; the website rebuilds automatically when new entries are archived.

Reference images include source information, and their copyrights remain with their respective creators or rights holders. The content is AI-assisted and may contain errors; consult the original works and cited sources for verification.
